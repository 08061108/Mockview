# 演示路线与截图

使用独立部署、虚构账号、合成 JD 和不含姓名/联系方式的自编简历。不要截取个人历史、JWT、模型配置页或原始日志。当前仓库不含产品截图资产；以下为录制说明，不是虚构运行截图。

1. 使用公开 RAG 示例初始化索引，JD 仅要求理解混合检索；登录后进入“分析证据并准备面试”。
2. 展示目标与材料引用、证据覆盖、可能的待补充问题。建议截图：准备页的目标和覆盖状态。
3. 启动 practice，展示真实 WebSocket 提问与一次回答/追问。建议截图：不含用户资料的问答区域。
4. 结束后展示最终评分、未评分标记、遗漏点、历史查看和 Markdown/打印导出。建议截图：合成报告概览。
5. 若存在有效低于 8 分的技能，从历史报告选弱项复练；没有弱项时不要捏造入口。展示新 case 的证据分析再开始。

录屏需标明使用真实模型还是 Mock。Mock 可验证协议与状态，不证明问题/评分质量。公开示例题库很小，真实模型无法产出足够有证据题目时应展示缺口，不通过关闭校验掩盖。

第四阶段曾用内部 Mock 和明确植入的合成低分历史完成一场两答复练、HITL 恢复与报告一致性验收；完整原始报告保留本地，不上传个人开发记录。本页面不将其描述为真实用户产品效果。
