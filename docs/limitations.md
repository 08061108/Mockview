# 当前限制与已知问题

## 已观察的非阻断问题

- 历史列表中已载入内存的 Session 可能显示“时间未知”、排序靠后。SessionManager 的内存摘要以空时间覆盖数据库摘要；数据库时间与报告仍在。后续应保留时间字段，定向检查载入前后列表一致性。
- 后端短暂不可用时，前端 getMe 对所有错误清除登录状态；API 重启空窗的 502 会导致重新登录。重新登录仍可恢复原准备任务。后续应区分鉴权拒绝与网络/5xx，并刷新健康提示。
- 内部 API 元数据版本为 0.2.0，包/Web 版本为 0.1.0；它们不是一份已发布的语义版本承诺，首次正式发布时再统一。

## 能力边界

- 单 API 进程、单 worker；未验收多实例、负载均衡、水平扩展或高并发吞吐。
- 真实模型质量、评分准确率、公平性、长期学习收益与成本延迟未形成充分公开指标。
- 简历个性化来自材料/目标绑定，不保证每题呈现项目经历；快速 practice 入口不同于准备主流程。
- 图片可使用 Vision，扫描 PDF 不保证自动转为 OCR；超限、格式签名不符或材料不足应明确处理。
- 旧版无 case/revision 或无有效最终评价的历史不能强行启动定向复练；源材料变化时 409，不提供完整历史材料归档。
- 复练追溯不等于跨会话语义去重；相同来源/技能集复用同一个 case，准备入口重复启动可能回到原 Session。
- 当前浏览器只保存最近准备指针；清空存储或换设备无完整准备任务列表。
- 公开合成语料仅有一个 RAG 示例，不是覆盖任意岗位的完整知识库；来源未确认的旧语料暂不进入公开清单。
- Agentic RAG、公开搜索、语义校验与 shadow 为可选实验，默认关闭。
- CLI、Gradio 旧入口不匹配当前鉴权/图流程，不作为受支持客户端。保留本地而非维护第二套产品。
- 打印导出生成 HTML；PDF 最终分页依赖浏览器，未宣称统一排版。

## 后续改进顺序

先处理已知显示/登录体验和发布前的来源、许可、文件清单；再根据真实使用反馈补模型质量证据。多实例、跨会话语义去重与更自主的检索只保留为可选方向，不作为本项目当前已完成能力。
